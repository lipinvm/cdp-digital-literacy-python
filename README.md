# Community Development Project — Digital Literacy & Python

A personal web-based field report documenting my **30-hour Community Development Project (CDP)** conducted across **six schools in Bihar, India**.

The project focused on introducing students to computers, digital literacy, binary concepts, and the fundamentals of Python programming.

## About the Project

The website presents the journey, curriculum, teaching methodology, activities, learning outcomes, and evidence from the project.

### Key Highlights

* 🏫 **6 schools visited**
* ⏱️ **30 hours of teaching**
* 💻 Computer fundamentals & digital literacy
* 🔢 Introduction to binary
* 🐍 Introduction to Python programming
* 📚 Classroom activities and student engagement
* 📜 Certificates and letters of appreciation
* 📍 Geo-tagged project evidence

## What I Learned

Beyond technical knowledge, the project helped me develop:

* Communication
* Presentation
* Adaptability
* Confidence
* Technical clarity
* Patience

The experience reinforced an important lesson: **knowing something and being able to explain it simply are two very different skills.**
